==================================================
PROJECT
==================================================

We are building an iOS-first creative photo application intended for eventual release on the Apple App Store.

The final product will allow users to:

- import multiple photos
- analyze those photos
- automatically select photos for collage roles
- convert some photos into cutouts / silhouettes / stickers
- generate premium editorial-style photo collages
- adapt visual treatment individually to different photos
- manually edit all important AI decisions
- later export static and lightweight animated social media compositions

The product is NOT a generic photo editor.

The product is NOT a web SaaS dashboard.

The product is NOT an AI demo.

The goal is a polished consumer iOS application.

==================================================
PERFORMANCE PRINCIPLES
==================================================

The app must eventually handle multiple high-resolution photos smoothly.

Architectural principles:

- never perform heavy image processing on the main UI thread
- future heavy processing should be isolated
- UI interaction must remain responsive
- future editor should use preview-resolution images
- final export should use original assets
- avoid unnecessary memory duplication
- avoid tightly coupling processing logic to SwiftUI views

Stage 01 does not implement heavy image processing.

However, its architecture must not prevent these optimizations later.

==================================================

Keep this architectural principle in mind.
